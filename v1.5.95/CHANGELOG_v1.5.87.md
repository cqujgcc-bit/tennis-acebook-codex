# v1.5.87 已结算未到账记录可重试

## 修复内容

- 历史被误标为 `settled` 但实际未到账的记录，现在允许进入重试流程。
- 钱包“已结算”列表增加“重新打款”入口，点击后后端先查询微信转账单：
  - `SUCCESS`：保持已结算，不会重复打款。
  - `WAIT_USER_CONFIRM` / `TRANSFERING`：恢复为 `confirming` 并拉起微信收款确认。
  - `ACCEPTED` / `PROCESSING` / `CANCELING`：恢复为 `confirming`，保持处理中。
  - `FAIL` / `CANCELLED` / 单号不存在：生成新转账单重试。
- 微信单号查询失败且不是“单号不存在”时，不再盲目换新单，避免重复转账风险。

## 使用方式

进入“我的钱包 - 已结算”，对未到账的球局点“重新打款”即可。
