# v1.5.90 切换商家转账场景 1005（佣金报酬）

## 背景

商户后台目前只开通了“佣金报酬”转账场景（场景 ID `1005`），无法申请场景 `1000`。
线上诊断已确认：用场景 `1000` 发起转账时，微信返回 `INVALID_REQUEST: 你尚未获取该转账场景`。

## 修复内容

- 部署流程会自动把服务器 `.env` 中的 `WXPAY_TRANSFER_SCENE_ID` 和 `WXPAY_TRANSFER_SCENE_INFO_TYPE` 更新为 `1005`。
- 转账请求按场景 `1005` 使用固定收款感知文案“佣金报酬”。
- 场景 `1005` 不再强制发送现金营销（场景 `1000`）才需要的 `transfer_scene_report_infos`，兼容微信 SDK 中该场景可不传报备字段的用法。
- 保留场景 `1000` 的原有报备字段逻辑；同时把场景 `1000` 的收款感知修正为微信样例使用的“现金奖励”。

## 使用方式

部署后可直接用 `auth.debugRetrySettlement` 对球局 65 发起真实重试，确认：
- 微信返回 `WAIT_USER_CONFIRM + packageInfo`：转账已创建，等待用户在微信确认收款。
- 若返回报备字段相关错误：根据错误码继续补齐场景 `1005` 的报备字段。
