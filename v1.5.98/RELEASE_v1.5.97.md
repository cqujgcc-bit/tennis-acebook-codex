# AceBook v1.5.97 上线前约球与新人体验修复

## 约球主流程

- 首页只查询今天及未来的招募球局，历史脏数据不再占用列表名额。
- 约球页默认加载今天及未来球局，历史球局切换到“历史”时再按最近时间加载。
- 历史卡片正确显示“已结束/已取消”，不再错误标记为“招募中”。
- 公开列表和详情按真实开球时间兜底校正过期状态；即使定时任务暂时延迟，也不会继续显示“招募中”。
- 服务端禁止创建开始时间已过的球局，并校验结束时间必须晚于开始时间。
- 公开球局中的手机号格式昵称统一显示为“球友”，避免手机号出现在列表和详情。

## 发布面与新人体验

- 暂停公开教练功能，移除课时包、成为教练和教练页入口；公开教练查询不再返回资料。
- 登录前增加用户协议、隐私政策可点击页面和明确同意勾选。
- 明确手机号授权为可选项，拒绝手机号授权仍可完成微信基础登录。
- 修复场地 API 重名覆盖，恢复后台预订平台配置下发。
- 修复“我的”消息角标 Tab 下标错误、未登录仍显示退出登录、统计名称不准确。
- 场地跳转失败提示改为用户可理解的操作说明，首页平台数量改为动态无关文案。
- “关于 AceBook”同步移除未上线的教练功能描述，并更新版本号。

## 尚需发布前确认

- 微信公众平台后台的隐私保护指引需与小程序内隐私政策保持一致。
- 服务器仍应持续调用 `/api/scheduled/close-expired-matches`，用于持久化球局完成状态及信用奖励；本版的接口兜底只负责保证用户看到的状态正确。
- 支付报名、退款和结算需在真机用小额订单完成最终回归。
