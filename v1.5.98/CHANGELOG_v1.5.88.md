# v1.5.88 商家转账待确认单据重试修复

## 修复内容

- 新增微信“撤销转账”调用：当历史结算单处于 `WAIT_USER_CONFIRM` / `TRANSFERING`，但数据库没有暂存 `package_info`（旧版本未保存），无法再次拉起微信收款确认页时，自动撤销旧单并重新发起一笔新转账，避免用户卡在“处理中”。
- 兼容旧版本留下的非法商户单号（例如带下划线、不符合微信 32 位字母数字规则）：查单返回 `PARAM_ERROR` / `INVALID_REQUEST` 时不再把用户卡死，而是按“原单无效”处理并重新发起打款。
- 钱包“待结算 / 处理中”和“已结算”列表增加球局 ID 显示（`#65` 等），方便和球局详情、后台日志核对。
- 临时在 `auth.wxpayDebug` 返回商家转账场景、转账回调地址配置，并新增带临时密钥的 `auth.debugSettlement` 诊断接口，用于确认 `match_settlements` 的真实状态。该诊断接口只返回结算状态/单号/是否已有确认包，不返回用户隐私字段，后续版本会移除。

## 使用方式

升级后进入“我的钱包 - 待结算 / 处理中”，点击对应球局的“重试打款”。如果旧单仍处于待确认且无确认包，服务端会自动撤销旧单并重新发起，随后小程序会尝试拉起微信收款确认页。
